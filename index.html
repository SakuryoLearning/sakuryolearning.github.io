What is Momiji

Momiji is a Japanese learning web app, aiming to be the one stop shop for those serious about learning Japanese, using Anki compatible SRS decks for learning vocabulary and Japanese characters. It is being developed full time and designed for my own use in learning Japanese. I wanted an app that has all the tools that I need to learn all aspects of Japanese in one place sharing one data source online and exportable to offline.

That means my dictionary knows the kanji I can read and write and which ones I can’t, as well as what words are in my Anki deck and how well I know them. I also want data on Japanese media and the data about my learning progress connected in a way where I know what media I should be able to understand and where I might be lacking and could improve.

All this and any other ideas that I think of along the way will be included in Momiji. Try it at momiji.app.

Momiji was called Sakuryo during its early development, so you’ll still see that name in some of the older screenshots.
